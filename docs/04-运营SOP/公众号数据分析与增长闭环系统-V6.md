# V6.0 公众号数据分析与增长闭环系统

## 目标

建立从内容发布、数据分析、爆款复盘到选题优化的增长闭环。

核心流程：

发布文章 → 数据采集 → 指标分析 → 爆款拆解 → 调整策略 → 优化选题

---

# 一、核心指标体系

## AI架构师江小北

目标：建立个人IP。

重点关注：

- 收藏率：代表内容价值
- 转发率：代表传播价值
- 新增关注：代表IP吸引力
- 长尾阅读：代表内容资产价值

## AI自由圈

目标：获取流量。

重点关注：

- 阅读量
- 点击率
- 分享率
- 粉丝增长

# 三、爆款文章分析模型

从五个维度分析：

## 1. 选题价值

是否解决目标用户真实问题。

## 2. 标题吸引力

是否产生点击欲望。

## 3. 内容结构

是否有清晰的问题、方案、观点。

## 4. 作者价值

是否体现个人经验。

## 5. 情绪价值

是否产生认同、焦虑、启发。

---

# 四、周复盘机制

每周固定复盘：

## 数据

- 发布数量
- 阅读最高文章
- 收藏最高文章
- 增粉最多文章

## 内容

分析：

- 哪些主题持续增长
- 哪些主题停止投入
- 下周重点方向
